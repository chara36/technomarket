О проекте ТехноМаркет

ТехноМаркет — учебный сайт интернет-магазина электроники, созданный Юрием для практики веб-технологий.

Цель проекта

Научиться создавать многостраничные сайты, оформлять их с помощью CSS и добавлять интерактивность с помощью JavaScript.

Используемые технологии

  • HTML5 — структура страниц
  • CSS3 — оформление и адаптивная вёрстка
  • JavaScript — события, DOM и работа с JSON
  • Bootstrap — готовые интерактивные компоненты
