# ТехноМаркет — учебный сайт

Автор: Юрий  
Тема: интернет-магазин электроники

## Файлы проекта
- `index.html` — главная страница
- `about.html` — страница «О проекте»
- `contacts.html` — контакты и форма обратной связи
- `style.css` — оформление и адаптивная вёрстка
- `script.js` — интерактивность сайта
- `data/projects.json` — данные для динамических карточек
- `images/headphones.svg` — иллюстрация на главной странице

## Реализовано во втором задании
1. Кнопка «Подробнее» показывает и скрывает текст.
2. Форма проверяет поля и email без перезагрузки страницы.
3. Карточки проектов загружаются из JSON через Fetch API.
4. Подключён Bootstrap 5 Modal.
5. JavaScript подключён отдельным файлом с атрибутом `defer`.

Для локальной проверки используйте Live Server или другой локальный HTTP-сервер. При открытии через `file://` запрос `fetch()` может не работать.
