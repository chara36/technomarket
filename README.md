# ТехноМаркет — учебный сайт

Автор: Юрий  
Тема: интернет-магазин электроники  
Технологии: HTML5, CSS3

## Файлы проекта
- `index.html` — главная страница
- `about.html` — страница «О проекте»
- `contacts.html` — страница контактов
- `style.css` — общие стили и адаптивная верстка
- `images/headphones.svg` — иллюстрация с альтернативным текстом в HTML

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `technomarket`.
2. Распакуйте архив и загрузите в корень репозитория файлы `index.html`, `about.html`, `contacts.html`, `style.css`, папку `images` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Дождитесь завершения публикации. В разделе Pages появится ссылка вида `https://ВАШ-ЛОГИН.github.io/technomarket/`.

## Проверка перед сдачей
- `index.html` лежит в корне.
- Имена файлов написаны латиницей без пробелов.
- На каждой странице есть UTF-8 и viewport.
- Навигация между тремя страницами работает.
- Все страницы подключают `style.css`.
- У изображения на главной странице есть `alt`.
- Все локальные пути относительные.
- Верстка адаптируется к узким экранам.

Примечание: сайт статический и не принимает реальные заказы. Контактные данные и товары демонстрационные.
